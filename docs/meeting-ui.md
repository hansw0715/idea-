# 회의 상세 · 예약 UI

2026-10-27 사용자 요청에 따라 기존 학교 파랑·회색 테마를 유지하고, 회의 코드와 안내를 간소화했다. 시각 기준은 `DESIGN.md` 상단의 현재 앱 디자인 기준과 `client/src/styles/tokens.css`다. 이전 KRDS 참고 기록의 색상·입력 형식은 현재 앱 기준보다 우선하지 않는다.

## 참여자와 시간표

- `MeetingParticipants`를 상세 화면과 예약 흐름에서 공유한다. 선택 상태는 체크/추가 아이콘, 제외 문구, `aria-pressed`로 구분한다.
- 선택한 팀원의 수업을 메인 시간표와 같은 회색 박스로 합쳐 그린다. 겹치거나 맞닿은 일정은 시작부터 끝까지 큰 박스 하나로 표시하고, 중간에 겹치는 인원이 달라져도 나누지 않는다. 실제 빈 간격과 서로 다른 요일은 분리한다. 기존 회의 예약은 별도 항목으로 유지한다.
- 회의 시간표의 수업 박스 안에는 과목명·인원·겹침 문구를 넣지 않는다. 접근성 이름과 누르면 열리는 상세 정보로 원래 일정을 확인할 수 있다.
- 목록 갱신 시 제외한 기존 팀원은 제외 상태를 유지한다. 새 팀원은 자동 포함하고 나간 팀원은 제거한다. 멤버 구성이 바뀌면 시간표를 다시 조회한다.
- 예약 중 인원·주·수업 시간이 바뀌면 시간·날짜·시설 선택을 초기화하고 1단계로 돌아간다. 새 결과를 기다리는 동안 옛 빈 시간과 다음 버튼을 사용할 수 없다. 이전 조회 응답은 무시한다.
- 예약 시간은 시간표에서 정각 1시간 단위로 끌어 선택한다. 빈 시간 목록과 시작·종료 입력은 사용하지 않는다. 시설별 제한은 기존 서버 판정을 따른다.
- 날짜는 현재 보고 있는 주의 월요일에 선택한 열의 요일을 더해 확정한다. 별도 날짜 선택이나 다음 주 같은 요일로 대체하는 동작은 없다. 지난 날짜·시각은 선택과 전송 전에 검사한다.
- 모바일에서 길게 누른 뒤 끌 때 예약 시트 본문이 가장자리에서 자동 스크롤된다.

## 배치와 피드백

- 코드·복사를 한 줄로 표시하고 복사 실패 시 선택 가능한 입력으로 대체한다.
- Stepper는 시간 → 시설 → 확인의 3단계다. 고정 하단에 선택한 날짜·시간과 다음 버튼을 표시한다.
- 팀원 선택은 시간표 위에 두고, 회의 상세와 예약 화면에서는 보조 일정 목록을 표시하지 않는다. 팀원별 농도·윤곽선 범례는 사용하지 않는다.
- 회의 시간표는 시간표 탭의 `TimetableGrid` 회색 면·시간당 높이·30분 보조선을 사용한다. 예약의 빈 시간은 기본 배경으로 두고, 선택 영역은 공용 시간표의 옅은 파란 배경·점선 테두리·시간 말풍선을 사용한다. 격자와 회색 일정 박스의 모서리는 직각이다. 선택 가능 시간 계산과 1시간 선택 단위는 유지하며, 회색 일정 박스 안에는 글자를 넣지 않는다.
- 기존 Sheet, Button, WeekNav, Alert, Toast를 재사용한다. 학교 계정 연동·실제 학교 신청·예약 취소 규칙은 기존 서버 계약을 따른다.
